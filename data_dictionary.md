# Data Dictionary

| Field | Description |
|---|---|
| city | City returned by provider |
| country | Country code |
| latitude / longitude | Location coordinates |
| observed_at_utc | Provider observation timestamp in UTC |
| pipeline_fetched_at_utc | Time this pipeline fetched the response |
| temperature_c | Air temperature (metric API units) |
| feels_like_c | Apparent temperature |
| humidity_pct | Relative humidity percentage |
| pressure_hpa | Atmospheric pressure |
| wind_speed_mps | Wind speed in metric units |
| wind_direction_deg | Wind direction in degrees, if available |
| cloudiness_pct | Cloud coverage percentage |
| weather_main | High-level weather category |
| weather_description | Provider description |
| visibility_m | Visibility in meters, if available |
